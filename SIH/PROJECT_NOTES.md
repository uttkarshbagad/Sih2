# Project Development Notes & Prerequisites

## Environment Prerequisites

- **Node.js**: v18.x or higher
- **Python**: v3.10+ with `fastapi`, `uvicorn`, `xgboost`, `shap`
- **Package Managers**: `npm` for Node services, `pip` for Python ML microservice

## System Services Port Allocation

- Frontend Dev Server: `3000`
- Backend API Server: `5000` / `5005`
- ML FastAPI Service: `8000` / `8008`
