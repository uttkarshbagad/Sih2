## Quick Reference

| Service | Stack | Port |
|---|---|---|
| ML Microservice | Python FastAPI / Uvicorn | **8008** |
| Backend API | Node.js Express | **5005** |
| Frontend App | React 18 + Vite | **3000** |

## Run It

**Option A — one click:** run `start-all.bat` in this folder.

**Option B — manual:**

```bash
# 1. ML microservice
cd ml-service
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8008 --reload

# 2. Backend API
cd backend
npm install && npm start

# 3. Frontend
cd frontend
npm install && npm run dev
```

Then open **http://localhost:3000** (Swagger docs at **http://localhost:8008/docs**).

## Status Snapshot

✅ Built: 11-page GIS decision-support UI, Leaflet risk map (10 Odisha districts), 7–30 day probabilistic forecasts, climate-signals panel, crop advisory engine, multilingual farmer mode (EN/हिन्दी/ଓଡ଼ିଆ), simulated SMS/WhatsApp console, XAI waterfall, historical trends, 22+ backend endpoints, FastAPI ML service.

⚠️ Prototype gaps: ML models are heuristic (not trained on real data), weather/GIS data is simulated in-memory, no live MongoDB, broadcast is simulated, no auth, no tests, no Docker/CI, and `node_modules`/`dist` are tracked in git. See the root README's *"Implemented vs. Remaining"* table for the full roadmap.
